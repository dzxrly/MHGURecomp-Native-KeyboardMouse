# 键鼠操作

[English](README.en.md)

根据实际装备自动选择近战或远程键位，并同步游戏中的按钮图标和按键说明。轻弩、重弩和弓使用远程预设，其余人类武器及猎猫使用近战预设。支持简体中文、繁体中文、英语、法语、德语、意大利语和西班牙语。

## 启用

在游戏目录的 `mhgurecomp.ini` 中设置，然后重启一次：

```ini
[Controls]
InputMode = Keyboard_Mouse_Input
```

之后更换装备或切换猎人／猎猫时，预设、提示文字和图标自动切换，无需修改配置或重启。旧配置中的 `KeyboardLayout` 不再参与选择。切换时会释放旧预设的按住状态并清空滚轮队列。

源码默认仍为 `InputMode = Original`，保留上游键鼠映射和手柄图标；手柄在两种输入模式下都能使用。下述直接角度实现针对当前导出的 NS 版 MHGU 1.4.0，不需要额外环境变量。

## 安装图标和按键说明

需要 Python 3.10 或更新版本，以及 Pillow 12.2 或更新版本。在仓库根目录执行，将示例路径换成原始游戏资源目录和游戏目录下的 `mods`：

```sh
python -m pip install "Pillow>=12.2"
python tools/build_keyboard_mouse_assets.py /path/to/game/romfs /path/to/mods/Keyboard_Mouse_Input_Auto --layout Auto
```

输出目录应为空，并位于输入目录之外。自动资源包同时包含两套提示：

```text
mods/
  Keyboard_Mouse_Input_Auto/
    romfs/
      keyboard_mouse_input.flag
      keyboard_mouse_prompts.bin
      nativeNX/
```

在 F1 设置菜单的 Mods 页启用这一个自动资源包。`Original` 模式会跳过它；旧的 `Melee`／`Ranged` 单预设资源包不再加载。保留标记文件和提示纹理数据文件。在 Mods 页禁用的资源包不会自动启用。

图标覆盖按钮字体、标题、菜单翻页、战斗界面、目标选择、狩技方向和大厅；按键说明随游戏语言和当前预设切换。图标显示主要绑定，不列出所有备用按键。游戏手册中整页手柄插图尚未替换，F1 设置菜单仍使用上游的英文或西班牙语。

菜单确认／交互在近战布局中是右键，在远程布局中是左键；两者都用 Space 返回。输入文字时，Enter 确认、Esc 取消。按 F2 释放鼠标后，点击游戏窗口可重新捕获。

Shift 对应游戏的通用奔跑，与强力冲刺分开。拔刀时，同一个游戏按钮 R 也可能用于防御或瞄准，具体动作取决于武器和操作类型。

远程表中的射击和装填按轻弩、重弩填写。弓在操作类型1下用 R 键拉弓、鼠标右键瞄准；类型2下这两个动作对调。

按键按 QWERTY 键盘的物理位置读取，其他键盘布局也使用相同位置。

## 鼠标视角与灵敏度

> 直接角度输入把鼠标的相对位移转换为游戏内部视角或武器瞄准角。相对位移计数不是屏幕像素；鼠标 DPI（每英寸计数）会影响同一物理移动产生的计数。

`[Mouse]` 下的 `MouseSensitivity` 控制基础灵敏度。普通任务视角、轻弩／重弩／弓瞄准及望远镜使用直接角度输入，不经过摇杆死区或速度上限，也不额外加入鼠标加速曲线。游戏原有的俯仰范围、射击后输入限制、入瞄准延迟和招式转向窗口继续生效；被屏蔽期间的位移会丢弃，恢复后不会补转。

菜单中的速度选项直接调节鼠标灵敏度，修改后即时生效：

| 菜单选项 | 对应鼠标操作 | 缓慢 | 标准 | 快速 |
| --- | --- | --- | --- | --- |
| 视角移动速度 | 普通任务视角 | 0.5倍 | 1倍 | 1.5倍 |
| 准星移动速度 | 轻弩、重弩、弓瞄准及望远镜 | 0.5倍 | 1倍 | 1.5倍 |

两项速度独立设置，并与 `MouseSensitivity` 相乘。默认基础标定下，水平移动1000计数在三档分别对应约20°、40°、60°。普通视角、快速瞄准和第一人称／望远镜分别遵循“视角操作”“瞄准操作”“瞄准时的操作”的反转设置。

五种“瞄准视角类型”保留游戏的入瞄准朝向、退出恢复和垂直范围差异。“视角初始位置”“目标视角操作／动作”及“视角依地形调整”仍由游戏处理。普通鼠标移动会在原手动视角阶段登记，使自动俯仰和地形调整能够识别手动操作；转动镜头不会强制把正在出招的近战角色转向镜头。

## 弓与猎猫

弓自动使用远程预设。收弓时左键保持 A 确认／交互，按 R（游戏 X）拔弓；拔弓后：

| 输入 | 弓操作类型1 | 弓操作类型2 |
| --- | --- | --- |
| 鼠标左键 | X：蓄力，松开发射 | 游戏设置对应的 R：蓄力，松开发射 |
| 鼠标右键 | 游戏设置对应的 R：按住瞄准 | X：点击切换瞄准，再次点击退出 |
| 鼠标侧键5 | A：弓副动作 | A：弓副动作 |

游戏的 R/ZR 互换设置参与弓鼠标映射。键盘仍按基础按键表工作；打开菜单后左键恢复为 A，松开鼠标会释放按下时对应的按钮。自动资源随近战／远程预设切换，弓的操作类型1／2目前仍显示基础远程提示，应按上表使用鼠标。

猎猫自动使用近战预设：左键 X 近战，右键 A 投掷回旋镖，R／鼠标侧键5 对应游戏 R。按住右键蓄力回旋镖时，再按住 R／鼠标侧键5 可精瞄。原游戏中拔出武器时 R 为防御，R+X 为上击；收起武器时可用 R+X+A 防御。滚轮通过 L+Y／L+A 选择支援行动；收起武器后按 F（Y）使用，拔出武器时按 R+F（R+Y）使用。具体支援行动的资格、消耗和动作限制保持原样。

## 兼容镜头与转换参数

村庄轨道镜头、固定弩炮及猎猫特殊瞄准保留原游戏的摇杆处理路径，鼠标在这些场景转换为右摇杆。`[MouseConversion]` 只影响这些兼容镜头；普通任务视角和已接入的弩、弓、望远镜直接输入不使用这些参数。兼容瞄准按实际镜头状态启用按轴死区补偿。修改转换参数后重启游戏。

```ini
[MouseConversion]
MinWindowMs = 8.0
FullStickSpeed = 1500.0
DeadzoneCompensation = 0.40
AimDeadzoneCompensation = 0.50
LowSpeedCutoff = 0.0
FrameTimeSmoothing = 0.25
```

> 相对位移计数是鼠标报告的移动量，不是屏幕像素；鼠标 DPI（每英寸计数）会影响同一物理移动产生的计数。归一化速度按 `计数/秒 × MouseSensitivity ÷ FullStickSpeed` 计算。

| 参数 | 范围／单位 | 作用 |
| --- | --- | --- |
| `MinWindowMs` | 1～50 毫秒 | 鼠标位移的平均窗口下限。增大后更平滑，停手后归零也更慢。实际窗口按完整帧间隔取整，最长100毫秒。 |
| `FullStickSpeed` | 100～100000 计数／秒 | 灵敏度为1时，达到满摇杆所需的鼠标速度。数值越大，同样鼠标速度对应的摇杆幅度越小。 |
| `DeadzoneCompensation` | 0～0.95，满摇杆幅度的比例 | 补偿游戏的摇杆死区。增大可加强小幅移动的响应，过低时小幅移动可能无法带动镜头。 |
| `AimDeadzoneCompensation` | 0～0.95，每个轴的满幅比例 | 兼容镜头进入瞄准状态时，对有移动的轴分别补偿。默认0.50使慢速水平、垂直和斜向输入都能触发右摇杆方向按键；设为0时使用普通视角的圆形补偿。 |
| `LowSpeedCutoff` | 0～0.1，归一化速度 | 忽略低于此值的移动。减小可保留更细微的输入；设为0时关闭这道过滤。 |
| `FrameTimeSmoothing` | 0.01～1，新帧间隔的权重 | 调整帧间隔估计。数值大时更快跟随帧率变化，小则更稳定；它不直接平滑鼠标速度。 |


普通兼容镜头使用圆形死区补偿；兼容瞄准使用按轴补偿，输出仍限制在摇杆圆内。其转速上限由游戏决定，同样鼠标距离不保证相同转角。失焦、释放鼠标、文字输入、PC 菜单或预设切换时会清空鼠标历史。

设置 `MHGU_NATIVE_MOUSE_LOG=1` 可记录接受的位移、镜头同步和弩弹／箭矢初始方向。调试控制文件的 `stopinput` 会取消自动按键、测试鼠标速度和按住状态；正常启动不会自动按住瞄准。

## 开发与检查

在正常构建环境中运行：

```sh
make test-settings test-keyboard-mouse test-settings-locale test-keyboard-mouse-assets
```

检查覆盖两套键位、道具／弹药滚轮、七种语言的说明、配置读写和鼠标采样。图标测试使用合成纹理和仓库中的 PC 素材，不需要游戏文件；鼠标测试检查输入采样，不测量实际镜头转角。

滚轮每次发送“按住 L → 按选择键 → 松开选择键 → 松开 L”，每阶段至少40毫秒。连续滚动会排队处理，失焦、输入文字或切换 PC 菜单时清空队列。

资源工具只修改按键文本和图标，保留其他资源。输出目录内的 `manifest.json` 记录修改项，并附有图标预览；生成的游戏资源留在本地。PC 图标素材的生成提示词见 [imagegen-prompts.txt](imagegen-prompts.txt)。

武器和风格的具体动作可查游戏内猎人笔记。相关按钮说明也可参考 Capcom 的 Generations 手册：[大剑](https://game.capcom.com/manual/MH_Gen/en/page-101.html)、[重弩](https://game.capcom.com/manual/MH_Gen/en/page-122.html)。
