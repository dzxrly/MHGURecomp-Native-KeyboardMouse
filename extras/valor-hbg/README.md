# 英勇重弩键鼠预设与 PC 按键图标

> `ValorHBG` 是这个本地版本新增的固定键鼠预设，`Original` 是上游原始布局。表中的“游戏按钮”指程序向游戏发送的虚拟 Switch 按钮。此版本基于 MHGURecomp 0.10.8。

[English installation and mapping guide](README.en.md)

在游戏目录的 `mhgurecomp.ini` 中设置以下内容，重启生效：

```ini
[Controls]
KeyboardPreset = ValorHBG
```

| PC 按键 | 游戏按钮 | 主要用途 |
| --- | --- | --- |
| WASD | 左摇杆 | 移动 |
| 鼠标移动 | 右摇杆 | 视角与准星，沿用原有速度转换 |
| 鼠标左键 | A | 射击、确认和交互 |
| 鼠标右键 | R | 瞄准 |
| R | X | 装填、拔刀 |
| F／鼠标侧键4 | Y | 收刀、按住进入英勇收刀、使用道具 |
| Space | B | 菜单返回、取消；闪避、解除蹲射及原游戏对应的动作衔接 |
| 左 Shift | R | 收起武器时的通用奔跑；不发送 B 或自动衔接英勇强力冲刺 |
| Q | L | 道具栏和原游戏的镜头操作 |
| C | X+A | 蹲射快捷输入，仍受风格和当前动作限制 |
| 滚轮上／下 | L+X／L+B | 逐格选择弹药，然后释放 L 确认 |
| Esc | ＋ | 打开、关闭游戏菜单 |
| Enter | ＋ | 保留原有菜单输入；输入文字时仍由文字系统处理 |
| Backspace | － | 原游戏的减号按钮 |
| Tab／鼠标中键 | ZL | 取决于游戏操作类型；类型1为切换目标 |
| T | ZR | 原游戏的 ZR |
| 1／2／3 | 方向上／右／下 | 操作类型1的狩技输入 |
| 方向键 | 十字方向键 | 菜单及原游戏操作 |
| Ctrl／Alt | 按下左／右摇杆 | 原游戏对应操作 |
| F1 | 主机设置菜单 | 沿用上游 |
| F2 | 释放鼠标捕获 | 点击窗口重新捕获 |

E 保留上游的 R 按钮绑定。本版本没有增加只在交互场景生效的 E 键逻辑。

Shift 与鼠标右键都是 R 的绑定：收武器时 R 是通用奔跑，持枪时 R 由游戏解释为瞄准。英勇强力冲刺的原有动作条件和输入衔接保留。英勇装填的时机仍由玩家自己掌握。

滚轮使用分阶段的 L、X/B、释放序列，不改变游戏的弹药数据。当前为固定按钮映射，没有自动识别游戏内所有菜单场景。

配套 `ValorHBG-PC-Controls` 资源 mod 支持游戏内提供的全部七种语言：简体中文、繁体中文、英语、法语、德语、意大利语和西班牙语。它修改各语言的显式按键说明、移动与弹药选择提示，以及共享按钮字体、标题确认按钮、菜单翻页、道具栏、目标选择、狩技方向和大厅的独立按钮贴图。各语言保留自己的文字和贴图背景，不能用一份英语贴图覆盖所有语言。

图标为固定的 PC 提示，按共享游戏按钮显示其主要绑定：例如 R 按钮显示鼠标右键，奔跑说明文字则使用 Shift；十字方向图标显示方向键，1/2/3 仍是上/右/下的别名。此资源 mod 也会影响手柄提示；切回 `Original` 或使用手柄提示时应禁用此 mod。烘焙进操作手册整张插画中的手柄图示尚未重绘，不能据此认为所有操作说明图片已完成替换。

西文说明使用 LMB／RMB／MMB 表示鼠标左／右／中键，避免过长的按钮名称破坏原来的换行。键帽和本文按键名称按 QWERTY 的物理位置标示；预设使用 SDL 扫描码，不会随 AZERTY、QWERTZ 等键盘布局翻译字母位置。游戏内“操作类型”仍决定虚拟按钮的含义，重弩建议先用操作类型1核对；F1 主机设置菜单只沿用上游的英／西语，不属于游戏内七种语言资源。

原始纹理中不属于输入图标的 BC3 压缩区块保留原字节，ARC 中未修改的资源保留原压缩数据。GMD 的条目标识、顺序、颜色和分页控制标记保留；同名文本存在包内差异时按包内原文处理。

这些改动只涉及主机输入和界面资源：弹药选择仍通过原游戏的 L+X/B 输入进行，英勇装填、强力冲刺、蹲射、伤害与动作时机均由游戏原逻辑处理。没有修改战斗代码或鼠标瞄准速度曲线。

从包含本功能的源码按仓库根目录 README 构建程序；仅生成资源 mod 不会给原版 exe 增加输入预设。`KeyboardPreset` 目前在 INI 中选择，修改后需要完全退出并重启游戏。

图标素材由 imagegen 生成，提示词见 `imagegen-prompts.txt`。Python 3.10+、Pillow 12.2+ 可在本地从自己的未修改游戏副本生成资源。以下命令从仓库根目录执行，替换两个示例路径；输出目录必须为空且与原始 romfs 分开：

```powershell
python -m pip install "Pillow>=12.2"
python tools/build_valor_hbg_assets.py "C:/path/to/game/romfs" "C:/path/to/ValorHBG-PC-Controls"
```

完全退出游戏后，将生成目录中的 `romfs` 放入 `mods/ValorHBG-PC-Controls/romfs`，再启用上面的 INI 预设并重启。不要与另一份旧版按键 mod 同时安装。卸载时移走该 mod 目录，并将 `KeyboardPreset` 改回 `Original`；原始游戏文件未被覆盖。

生成目录还包含 `manifest.json` 和贴图预览。清单记录各语言修改条目及重打包的 ARC；预览用于检查游戏资源，不应提交到公开仓库。仓库只提供输入实现、生成脚本、PC 图标源素材和说明，不包含原游戏文件或生成后的 mod。

无需游戏副本的回归检查：在构建环境中执行 `make test-settings test-valor-hbg test-settings-locale`。其中输入检查覆盖 30/60/120/240 FPS 下的滚轮脉冲，以及 Shift、Esc、菜单返回和鼠标绑定；文本检查覆盖七种语言、组合键、摇杆点击和格式标记保留。
